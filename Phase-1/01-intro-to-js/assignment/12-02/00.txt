Key Concepts to Remember
.reduce() pattern:
array.reduce((accumulator, currentValue) => {
    // Logic to update accumulator
    return accumulator;  // MUST return accumulator
}, initialValue);  // Don't forget initial value!
.find() returns:
The element itself (or undefined)
.findIndex() returns:
The index number (or -1 if not found)
Common reduce use cases:
Sum/Product: Start with 0 or 1
Count: Start with empty object {}
Group: Start with empty object {}
Flatten: Start with empty array []
Convert array to object: Start with {}
Find max/min: Start with arr[0]
